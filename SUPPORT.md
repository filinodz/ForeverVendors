# Support

Use [Discussions](https://github.com/filinodz/ForeverVendors/discussions) for setup
help and [Issues](https://github.com/filinodz/ForeverVendors/issues) for reproducible
script defects or verified item corrections.

Include the ForeverRepack version, the three verification counts from the README,
the worldserver restart status and sanitized error text. Never share database
credentials or the full contents of `worldserver.conf`.
