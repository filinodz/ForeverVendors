# Security policy

Report unsafe SQL, credential exposure or destructive removal behavior privately
through [GitHub Security Advisories](https://github.com/filinodz/ForeverVendors/security/advisories/new).

Always review scripts before import, back up the `world` database and stop
worldserver first. Run the bundled MySQL client with an interactive password prompt;
do not place database passwords in scripts, screenshots, issue reports or command
history.
